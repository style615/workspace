# Before publishing

1. Upload **only** `.github/profile/README.md` into the public `.github` repository if you are updating your organization profile.
2. `REPOSITORY-STRUCTURE.md` is an internal planning guide; keep it locally or in a private repository.
3. `s615-ecosystem/README.md` and `s615-docs/README.md` are optional templates for separate documentation-only public repositories.
4. Do not upload the entire ZIP into a public GitHub repository.
5. Keep all product source repositories private; review any existing public repositories separately.
6. Check wording about Sentinel's previous open-source description and any applicable licensing commitments before changing its publication status.
